## 🎓 Overview  
**Student-Assist** is an anonymous complaint & feedback platform built especially for students.  
It helps students speak up without revealing their identity — whether for complaints, feedback or suggestions — and gives administrators tools to monitor, manage & report efficiently.

## 🧩 Key Features  
- Submit complaints or feedback **anonymously** (student name hidden).  
- View all posted complaints (visible to students & admin).  
- Admin dashboard to:  
  - Change complaint status (Pending → In-Progress → Solved).  
  - Detect suspicious posts (keywords like *money*, *!!!*, etc) and flag fake or misuse.  
  - View weekly summary reports and **download** them for record.  
- Clean frontend built with HTML, CSS & JS.  
- Secure backend powered by PHP + MySQL (via phpMyAdmin).
